Drop SUNO-generated menu music here:

  One track:        menu-theme.mp3        (loops seamlessly)
  Multiple tracks:  menu-theme-1.mp3      (played in a shuffled cycle,
                    menu-theme-2.mp3       never the same track twice
                    menu-theme-3.mp3       in a row; up to -4 supported)
                    menu-theme-4.mp3

The app discovers whatever is present automatically and stays silent if
nothing is here. Optional later additions: launch stinger.

NOTE: these bundled tracks are only the FALLBACK. End users add their own
music via the 📁 button in the app's nav bar, which opens
%APPDATA%\com.dosdeck.app\music\ — any mp3/ogg/wav/flac/m4a dropped there
plays in alphabetical order and takes priority over the bundled tracks.
